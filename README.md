# 🌐 Personal Profile Webpage

## 🌐 Live Demo
Check out the live website here: [Personal Profile Website](https://rishikathallapally.github.io/profile-webpage/)

A simple, beginner-friendly personal profile webpage built using **HTML5 and CSS3 only**. This project was created as part of my journey into web development to practise the fundamentals of HTML and CSS by building a webpage from scratch.

## 📌 About the Project

This website introduces me, showcases my technical skills, lists my hands-on projects, and provides contact information. It features a clean layout with simple styling and navigation between sections.

As a beginner project, it focuses on understanding the basics of webpage structure, styling, and responsive design without using JavaScript, frameworks, or external libraries.

## ✨ Features

- **Introduction:** A header displaying my name and a short introduction.
- **About Me:** A brief description of my background and career goals.
- **Technical Skills:** Skills organised into categories.
- **Projects:** A list of hands-on projects.
- **Contact Section:** Links for getting in touch.
- **Section Navigation:** Navigation links that jump to different sections of the webpage.
- **CSS Styling:** Custom colours, fonts, borders, rounded corners, spacing, and hover effects.
- **Responsive Design:** Basic responsive styling for smaller screens.

## 🛠️ Technologies Used

- **HTML5** — To structure the webpage and organise its content.
- **CSS3** — To style the webpage and create its layout and visual appearance.

**Note:** This project uses only HTML and CSS. No JavaScript, frameworks, or libraries are used.

## 📂 Project Structure

personal-profile/
├── index.html
├── style.css
└── README.md

- `index.html` — Contains the structure and content of the webpage.
- `style.css` — Contains the styles used to customise the webpage.
- `README.md` — Provides information about the project.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the different sections using the navigation menu.

You can also open the project in Visual Studio Code and use the Live Server extension to preview your changes while developing.

## 🎯 Learning Outcomes

Through this project, I practised:

- Creating the basic structure of an HTML document.
- Using semantic HTML elements such as `<header>`, `<nav>`, `<main>`, and `<section>`.
- Creating headings, paragraphs, ordered lists, and unordered lists.
- Linking webpage sections using IDs and anchor links.
- Connecting an external CSS stylesheet to HTML.
- Using CSS selectors and properties.
- Understanding margins, padding, borders, and the CSS box model.
- Applying colours, fonts, rounded corners, and shadow effects.
- Adding hover effects to links.
- Exploring responsive design using CSS media queries.

## 🌱 What I Learned

This project helped me understand how HTML and CSS work together to build a webpage. It also gave me practical experience in organising content, styling individual sections, and making a website more user-friendly.

As a beginner, I am continuing to improve my understanding of web development by building more projects and experimenting with different layouts and styles.
